A practical export guide

How to export Mermaid diagrams as PNG or SVG

Turn Mermaid source into an image for a document, a slide, or a web page. Here is how to choose the format, remove the background, and get the right size in Pele Studio.

1. Prepare your Mermaid source

Open the Pele Studio editor and paste your Mermaid source into the code panel. On a phone, select the Code tab. You can also use Import to open a .mmd file or a Markdown file containing a fenced Mermaid block.

For a small example, copy this flowchart. It shows a review loop: keep editing until the diagram is ready to export.

The editor link opens your usual working session; it does not load this example automatically. Save a separate copy of any source you want to keep before replacing it.

Check the live preview and fix any reported syntax errors. The last valid diagram can remain visible while the current source has an error. Choose a theme and font in the design panel, and give the diagram a title to set a useful export filename.

2. Export a PNG at the right size

PNG is a raster image. It is useful when you want the rendered text and shapes to look consistent in a slide or document without relying on that application’s SVG font support.

  1. Open Export in the toolbar. On a phone, use the export icon. You can also use Ctrl + E on Windows or Linux, or ⌘ + E on macOS.
  2. Under Format, select PNG.
  3. Choose Resolution: 1×, 2×, 3×, or 4×. Higher scales produce more pixels for the same diagram, which helps when you need to display it larger. Start with 2× and check the output dimensions shown near the filename.
  4. Choose your Background, then adjust Padding to leave space around the diagram. For example, start with 32 px and reduce it if you need a tighter crop. The slider runs from 0 to 160 px.
  5. Review the export preview and select Download PNG. On phones with file sharing available, the download button may simply say Download. Copy image is another option if your browser supports image clipboard access.

Scale can be reduced automatically

Very large diagrams can exceed browser canvas limits. Pele Studio caps the effective PNG scale and shows a reduction notice when it is lower than your selection. Trust the displayed pixel dimensions rather than assuming 4× was used. Preview zoom does not change export resolution: the export is rendered fresh at its natural size.

A higher scale does not replace readable typography. If labels look too small at the final display size, increase the font size in the design panel before exporting.

3. Use a transparent background

In the export dialog, under Background, select None. This is the transparent option for both PNG and SVG. Theme includes the theme’s background color; Custom lets you pick a different solid color.

The checkerboard behind the preview indicates transparency. It is a preview aid, not a pattern added to the exported image. Padding still adds space around a transparent diagram, but that space has no solid background.

Removing the background does not recolor the diagram or make the node fills transparent. A dark theme can have light text that becomes difficult to see on a white slide. Choose colors for the intended destination, then place the downloaded image on that actual background to check contrast.

4. Choose SVG for a vector export

SVG keeps the diagram as vector shapes and text, making it useful for resizing in applications that support the file. It does not have the PNG resolution selector.

  1. Open Export and select SVG under Format.
  2. Set Background to Theme, None, or Custom, and adjust Padding.
  3. Decide whether to keep Embed fonts enabled. For bundled fonts, embedding includes font data in the SVG for viewers that support it. Disabling it can make the SVG smaller, but the viewer must supply a matching font or use a fallback.
  4. Choose Download SVG, or Copy SVG code if you need the markup and your browser allows clipboard access.

The export resolves the diagram’s CSS variables into explicit values so its colors are not dependent on the editor’s styles. This improves portability, but font handling still depends on the destination application.

5. Watch for font substitution in PowerPoint

Embedding fonts is not a guarantee of identical SVG typography everywhere. Apps such as PowerPoint and Illustrator ignore embedded @font-face rules and use an installed font or fallback. Text can change appearance or fit differently even when the shapes remain sharp.

If exact typography matters in those apps, use PNG and choose enough resolution for the size you will place it at. For SVG, use a font available on the destination computer and inspect the imported result. Classic system-font selections depend on installed fonts; they do not have a bundled font file for Pele Studio to embed.

6. Check the downloaded result

The PNG looks blurry when enlarged
Export at a higher resolution and check for an automatic scale-reduction notice. Avoid stretching a raster image beyond its useful pixel size; consider SVG if the destination supports it.
The transparent image appears to have a solid background
Some image viewers display transparent areas on white or black. Place the file on a colored background to check it, and confirm that Background → None was selected.
Copying does not work
Clipboard support and permissions vary by browser. Use the download button instead. Where supported, the dialog also offers a system share option.
You need to edit the diagram later
Keep the Mermaid source separately as text, for example in a .mmd file. Browser-local autosave is a working-session convenience, not a cloud backup, and exporting an image does not preserve an editable Mermaid document.
