Text in. Diagram out.

Mermaid describes diagrams using text: nodes, connections, labels, and layout directions. Pele Studio pairs a source editor with a live preview so you can work on the structure without drawing every shape by hand.

Start by typing, choose a starter diagram from Templates, or import a .mmd file or Markdown containing a Mermaid code block. Syntax highlighting and inline errors help you spot problems. While you fix an error, the preview keeps the last valid diagram on screen; it is not confirmation that the current source is valid.

Pan and zoom to inspect the result, then use the design controls to refine it. On a phone, the Code, Preview, and Design tabs keep these tools within reach.

Make the diagram fit its destination

Choose a light or dark theme, try Surprise me for a coordinated palette, or adjust individual colors. Typography controls include bundled and system fonts, font size, and a setting to keep the diagram size while changing text size. Corner radius and chart-series colors offer further control.

Export options are separate from preview zoom. Choose PNG for a raster image or SVG for a vector file, then set the background and padding. PNG resolution choices run from 1× to 4×, with automatic reduction for large diagrams to stay within browser canvas limits.

For transparent exports, select None under Background. For presentation software, check font support before choosing SVG. The Mermaid-to-PNG and SVG guide walks through both formats and their trade-offs.

Your working session

Local autosave, not cloud storage

Pele Studio stores your current diagram source, title, theme, and export settings in this browser using IndexedDB. The editor can restore that session when you return in the same browser profile. It does not synchronize your diagrams across devices or provide a cloud document library.

Autosave is best effort: private browsing, storage limits, or clearing site data can prevent saving or remove saved work. Keep a separate copy of important Mermaid source in a text file. PNG and SVG exports are images, not backups of your editable source.

Built on Pele

Rendering, parsing, and layout come from Pele, a diagram-rendering library with Mermaid-compatible syntax. Pele Studio is an unofficial editor built on that library and is not affiliated with the Pele project. The Pele name and logo belong to their creator, kepano.

You can inspect the implementation and self-hosting instructions in the Pele Studio source repository.
